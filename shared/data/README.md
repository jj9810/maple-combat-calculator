# shared/data

전투 계산기에서 사용하는 각종 설정 및 데이터 파일들입니다.

## common
- `class_mapping.yaml`: 직업 명칭 정규화를 위한 매핑 데이터.

## classes
- 직업별 스킬 계수, 타수, 버프 효과 정보를 담은 YAML 파일들입니다.
- 현재 데이터는 검증되지 않은 임시값이며 검증 및 업데이트 예정입니다.

## mobs
- 몬스터(보스)의 레벨, 방어율, 속성 저항, 요구 포스 등 상세 스펙 데이터입니다.

## policies
- 캐릭터의 스킬 사용 순서나 우선순위를 정의하는 정책 파일입니다. (현재 Nexon API 플로우에선 미사용)

## presets
- 가상의 캐릭터 스탯 세팅 정보입니다. (현재 Nexon API 플로우에선 미사용)
